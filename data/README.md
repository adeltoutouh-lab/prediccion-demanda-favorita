# Datos

Los datos utilizados en este proyecto proceden de la competición pública de Kaggle:

https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data

## Pasos de descarga

1. Crear o iniciar sesión en una cuenta de Kaggle.
2. Abrir la página de datos de la competición.
3. Aceptar las condiciones de uso cuando se solicite.
4. Descargar y descomprimir los archivos.
5. Guardar los CSV dentro de esta carpeta `data/`.

Archivos esperados:

- `train.csv`
- `test.csv`
- `stores.csv`
- `transactions.csv`
- `holidays_events.csv`
- `oil.csv`
- `sample_submission.csv`

Los CSV están excluidos mediante `.gitignore` y no deben subirse al repositorio público.

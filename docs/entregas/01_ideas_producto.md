## Idea 1. Sistema de analítica web para mejorar una página real

### Problema o necesidad

Muchas páginas web reciben visitas, pero sus responsables no saben con claridad qué hacen los usuarios dentro de ellas. Puede resultar difícil saber qué páginas interesan más, en qué punto abandonan la navegación, qué enlaces reciben más clics o si el tráfico procede de personas reales o de bots. Sin esta información, muchas decisiones sobre contenidos, diseño y campañas se toman principalmente por intuición.

### Impacto o valor

La idea consiste en crear un sistema de análisis utilizando datos de Google Analytics u otra herramienta equivalente. Se estudiarían métricas como usuarios únicos, páginas más visitadas, clics, dispositivos, origen geográfico, navegador, profundidad de scroll, tiempo de permanencia, días y horas con más tráfico y rendimiento de campañas de correo. El resultado podría ayudar a mejorar la experiencia de usuario, priorizar los contenidos que funcionan y entender mejor qué acciones generan resultados.

### Motivación personal

Me interesa esta idea porque permite trabajar con datos generados por una página real y porque combina análisis de negocio, visualización y comportamiento de usuarios. También me parece útil para entender mejor cómo se mide el funcionamiento de un producto digital más allá del número total de visitas.

## Idea 2. Análisis automático de reseñas para detectar insatisfacción

### Problema o necesidad

Las empresas que reciben muchas reseñas pueden tener dificultades para leerlas y clasificarlas manualmente. Una puntuación baja indica que existe un problema, pero no siempre explica de forma rápida si la causa está relacionada con el producto, el envío, la atención al cliente, el precio o cualquier otro aspecto del servicio.

### Impacto o valor

La propuesta sería desarrollar un sistema de procesamiento de lenguaje natural que analizara las reseñas, estimara su sentimiento y agrupara los principales motivos de satisfacción e insatisfacción. El producto podría incluir un panel con la evolución de las valoraciones, palabras y temas frecuentes, categorías de queja y alertas cuando aumenten los comentarios negativos. Esto permitiría resumir grandes volúmenes de texto y detectar problemas repetidos con mayor rapidez.

### Motivación personal

Esta idea me interesa porque introduce una parte de inteligencia artificial aplicada al lenguaje y permite trabajar con información que no está estructurada de forma tradicional. También tiene una aplicación empresarial fácil de entender, ya que las reseñas contienen información directa sobre la experiencia de los clientes.

## Idea 3. Predicción de ventas para una cadena de supermercados

### Problema o necesidad

Una cadena de supermercados necesita estimar cuánto puede vender en cada tienda y familia de productos. Las ventas cambian según el día, las promociones, los festivos, la estacionalidad y las diferencias entre tiendas, por lo que no siempre es sencillo anticiparlas utilizando solo una media histórica.

En un caso real, una previsión de ventas puede servir como una señal de apoyo para la planificación. Sin embargo, con datos de ventas por sí solos no se puede saber si una venta baja significa realmente poca demanda o si hubo una rotura de stock. Por eso esta idea se centra en predecir ventas registradas y no en automatizar decisiones de inventario.

### Impacto o valor

La idea consiste en construir un modelo de predicción de ventas a partir del histórico diario de una empresa real. El sistema tendría en cuenta la tienda, la familia de producto, las promociones, los festivos y otras variables temporales. El resultado se podría mostrar en un dashboard para comparar ventas reales y previstas, revisar el error y detectar en qué tiendas o familias el modelo funciona mejor o peor.

### Motivación personal

Es la idea que más me interesa porque permite combinar análisis exploratorio, series temporales, machine learning y visualización. Además, el resultado se puede evaluar de forma bastante clara comparando las predicciones con las ventas observadas y se puede presentar como un producto funcional mediante un dashboard.
